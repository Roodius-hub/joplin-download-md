## Installation Help

### First-Time Setup

1. **Download** the appropriate version for your platform
2. **Install** following platform-specific instructions
3. **Launch** Joplin
4. **(Optional)** Configure synchronization
5. **Start** taking notes!

### Troubleshooting

**Windows:**
- If SmartScreen warns, click "More info" → "Run anyway"
- Antivirus may flag the installer - this is a false positive

**macOS:**
- If blocked by Gatekeeper: System Preferences → Security & Privacy → "Open Anyway"
- For M1/M2/M3: Use the ARM64 version for better performance

**Linux:**
- AppImage: Make executable with `chmod +x Joplin-*.AppImage`
- If libfuse is missing: `sudo apt install libfuse2`

## Why Choose Joplin?

### ✦ Your Data, Your Control

- **No lock-in:** Open format, export anytime
- **No forced cloud:** Sync only if you want
- **No compromises:** Full-featured, always free

### ✦ Core Features

- ✍️ **Markdown editor** with live preview
- 🔐 **End-to-end encryption** for security
- 🔄 **Cross-platform sync** across all devices
- ⚡ **Offline-first** - works without internet
- 📂 **Open data format** - never trapped
- 🔌 **Plugin system** - extend functionality
- 📎 **Attachments** - images, PDFs, files
- 🏷️ **Tags and notebooks** - organize your way
- 🔍 **Full-text search** - find anything instantly

### ✦ Philosophy

> Your notes belong to you.

Joplin is built on principles of:
- **Portability** - Take your data anywhere
- **Durability** - Notes that last forever
- **Independence** - No service dependencies
